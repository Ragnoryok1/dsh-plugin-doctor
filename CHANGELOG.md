# Changelog

Все значимые изменения плагина. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[SemVer](https://semver.org/lang/ru/).

Пакет следует за харнессом: проверено на `dsh 0.2.1-alpha.1`
(диапазон `>=0.1.0-rc.2 <0.3.0` для `@deepseek-ai/dsh-client-locale`).

## [0.1.0] — 2026-10-06

### Добавлено

- Вкладка **«Диагностика»** в разделе «Встроенные плагины» рядом с инвентарём.
- Проверка плагинов, которые **не загрузились**: показывается сообщение об ошибке,
  которое вернул сам плагин.
- Проверка **объявленных, но не запущенных** строк бандлов — так выглядит след
  неудачного обновления, когда запись есть, а живой записи у неё нет.
- Проверка записей, которыми **нельзя управлять из интерфейса**, с указанием причины
  (`management-required`, `unaddressable` и другие).
- Показ **выключенных** плагинов и предупреждений об исключениях по версиям.
- Счётчик проверенного: «Проверено плагинов: N, строк бандлов: M». Без него ответ
  «проблем нет» неотличим от «проверка ничего не увидела».

### Особенности реализации

- Данные берутся только из **штатных сервисов**: `remote.pluginManager` через
  Remote-протокол. Плагин не читает файлы и внутренности других пакетов, поэтому
  переживает обновления харнесса.
- Ответы Remote распаковываются из конверта `{ ok, value }`: проверка
  `Array.isArray` на самом ответе молча давала «0 плагинов».
- «Проблемами» считаются только ошибки. Справочные разделы (выключенные записи,
  записи, которыми владеет профиль) видны, но не делают здоровый профиль сломанным.
- Текст интерфейса переводится: `plugin-doctor` регистрируется для `ru` и `en`.
